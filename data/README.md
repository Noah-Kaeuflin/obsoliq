# Data Folder

## Complete KPI Control

`synthetic-kpi-calculability-control.csv` contains four fictitious EUR positions for the seven Overview KPIs, including a permitted blank-stock derivation, a genuine zero and overlapping/capped risk inputs. [`KPI_CONTROL_IMPORT.md`](KPI_CONTROL_IMPORT.md) documents the normal visible import, independent expectations and export reconciliation. It is separate from the unchanged 102-row error demo and contains no personal/customer data. Normal file uploads retain the ordinary upload trust boundary; the synthetic filename is not privileged authorization.

## Synthetic PO Extension

`demo/purchase-orders.csv` and `demo/purchase-orders-update.csv` are hand-authored synthetic fixtures for RECOVERY-LOOP-01A. Fictitious suppliers, buyers, orders and source system SYNTHETIC-ONLY are used. They contain no real customer or personal data and assert no expert/pilot validation. The update changes one open quantity and its evidenced value.

`templates/purchase-orders-template.csv` is a structural template with headers only, not a usable dataset. `node scripts/generate-purchase-orders-demo.cjs` (generator version `po-demo-v1`) creates `js/purchase-orders/purchase-orders-demo.js` byte-deterministically from those three CSVs, normalized to LF. Input and output fingerprints are recorded by the canonical SHA256 manifest. Explicit demo imports and review exports retain classification `synthetic`; ordinary user uploads do not automatically inherit that classification.

The accepted Inventory, Material Master and Consumption History demo files, their generator and default three-package load are unchanged. The PO extension is an explicit UI action, not a fourth implicit default import.

This folder is for synthetic sample data, structural templates and test data only.

## Linked Demo

The Inventory/Material/History files in `demo/` are generated by `scripts/generate-linked-demo-data.cjs` as one linked synthetic source set:

- `inventory-snapshot.csv`: 102 Inventory rows
- `material-master.csv`: 98 Material Master rows
- `consumption-history.csv`: 2,260 History rows
- `demo-expectations.json`: independent cohort, relationship, readiness and hash oracle

The frozen analysis date is `2026-08-31` UTC. Every identifier and business value is fictitious. The generator also produces `demo-data.js` for direct browser loading; static contracts require its payloads to match these files exactly.

`templates/` contains header-only structural templates for Material Master and Consumption History. They contain no business records and are expected to fail import until a user adds valid rows.

Allowed:

- small reproducible sample files
- anonymized fixtures used for local MVP testing
- files that preserve spreadsheet safety, leading-zero identifiers and SAP-like column structure

Not allowed in Git:

- real SAP exports
- customer or pilot data
- personal data
- credentials, tokens or connection strings
- confidential commercial data

Private files must be kept outside the repository or in an ignored folder such as `data/private/`.
